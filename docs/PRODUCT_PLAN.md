# JoyData 问卷系统产品方案

## 1. 产品定位

JoyData 问卷系统不是旧问卷后台的界面搬迁，而是面向全球游戏玩家的统一调研工作台。

产品采用“一套管理后台、两个区域交付面、多语言原生支持”的设计：

- 管理后台统一嵌入 JoyData，复用项目、成员、角色和数据分析能力。
- 国内与海外问卷在工作空间、域名、数据存储和合规配置上严格隔离。
- 问卷结构可以在区域间复制，答卷数据不能跨区域混用。
- 多语言属于问卷结构的一部分，而不是运营手动维护的多份问卷。

## 2. 核心用户

### 运营

- 快速复制历史问卷和模板。
- 选择游戏、地区、渠道和语言后直接发布。
- 查看回收进度、完成率和异常情况。
- 尽量不接触复杂技术配置。

### 用户研究

- 创建复杂题型和跳题逻辑。
- 维护跨语言题干、选项和提示文本。
- 对不同语言、国家、渠道和玩家群体进行对比分析。
- 管理协作者和数据权限。

### 管理员

- 管理模板、区域、合规策略、角色权限和集成配置。
- 审计发布、数据导出和配置变更。

### 玩家

- 打开链接后自动匹配合适语言。
- 能够手动切换语言。
- 在移动端快速完成问卷。
- 清楚了解隐私、奖励和数据使用说明。

## 3. 产品原则

1. 默认替用户完成判断，高级配置按需展开。
2. 问卷结构、翻译内容、发布实例和答卷数据分层管理。
3. 国内/海外必须显式区分，任何跨区域复制都需要二次确认。
4. 问卷组只负责归类，答卷数据默认按问卷实例独立展示。
5. 运营使用路径短，用研能力上限高。
6. 所有关键配置支持保存草稿、自动保存和变更记录。

## 4. 信息架构

```text
JoyData
└─ 用研
   ├─ 问卷工作台
   │  ├─ 全部问卷
   │  ├─ 我创建的
   │  ├─ 与我协作
   │  ├─ 草稿
   │  └─ 回收站
   ├─ 待填写
   ├─ 模板中心
   ├─ 主题中心
   └─ 管理配置
      ├─ 区域与合规策略
      ├─ Webhook
      └─ 操作日志
```

单份问卷内：

```text
概览
├─ 编辑器
├─ 多语言
├─ 逻辑
├─ 外观
├─ 发布与回收
├─ 答卷数据
├─ 分析报告
└─ 协作与权限
```

## 5. 核心对象模型

### Project

JoyData 项目。决定成员、游戏和基础数据权限。

### Workspace

区域工作空间，取值为 `GLOBAL` 或 `CHINA`。决定数据存储、前台域名、登录方式和合规策略。

### Survey

问卷主档，包含名称、归属项目、问卷组、负责人、状态和问卷结构。

### SurveyLanguage

问卷语言版本。结构共享，题干、选项、提示、完成页和隐私文本独立翻译。

### Publication

一次发布实例。包含区域、渠道、默认语言、可切换语言、时间、登录限制、答题次数和回调地址。

### Response

答卷数据，必须归属某个问卷、发布实例、区域和语言。

### Collaborator

问卷协作者及权限，包括编辑、发布、查看数据、导出和管理成员。

## 6. 多语言策略

默认语言判断顺序：

1. 发布渠道显式指定语言。
2. 玩家账号语言。
3. 浏览器或系统语言。
4. 问卷默认语言。

玩家始终可以在前台手动切换到已发布语言。

翻译状态分为：

- 未开始
- 翻译中
- 待校对
- 已完成
- 原文已变更

原文修改后，其他语言对应字段自动标记为“原文已变更”，防止旧翻译直接发布。

## 7. 国内与海外

后台采用同一套界面，通过明显的工作空间切换器切换。

区域差异包括：

- 数据存储位置
- 问卷访问域名
- 隐私政策与同意方式
- 可用登录方式
- 数据推送目标
- 默认语言

支持“复制到另一工作空间”，复制内容包括题目、逻辑、翻译和主题，但不复制答卷、链接、登录配置和 Webhook。

## 8. 页面说明

### 问卷工作台

- 区域工作空间切换
- 项目和问卷组筛选
- 状态、语言、负责人筛选
- 回收量、完成率和更新时间
- 创建、复制、移动、归档和删除

### 创建问卷

四步向导：

1. 基础信息：名称、项目、问卷组、场景。
2. 区域：国内或海外。
3. 语言：默认语言和可用语言。
4. 创建方式：空白、模板、复制已有问卷。

### 编辑器

三栏布局：

- 左侧：题型库和页面结构。
- 中间：问卷画布。
- 右侧：题目属性、验证、显示和翻译状态。

一期题型包括单选、多选、下拉、填空、评分、NPS、图片、排序、矩阵、分页和说明文本。

### 发布与回收

- 公开链接、渠道链接和指定填写。
- JM、Line 或匿名填写。
- IP、账号、设备和总量限制。
- 开始/结束时间。
- 完成页和跳转规则。
- Webhook 和测试推送。

### 答卷数据

- 答卷列表、字段筛选和详情。
- 导出、附件下载和异常标记。
- 按问卷实例隔离数据。
- 默认不跨区域查询。

### 分析报告

- 回收量、浏览量、完成率和平均耗时。
- 单题统计、漏斗、语言和渠道对比。
- 国家/地区、设备和来源分布。
- 支持保存筛选条件和分享只读报告。

## 9. 权限模型

| 权限 | 创建人 | 编辑者 | 发布者 | 分析者 | 只读 |
|---|---:|---:|---:|---:|---:|
| 编辑结构 | 是 | 是 | 否 | 否 | 否 |
| 管理翻译 | 是 | 是 | 否 | 否 | 否 |
| 发布/停止 | 是 | 否 | 是 | 否 | 否 |
| 查看答卷 | 是 | 可配置 | 可配置 | 是 | 否 |
| 导出答卷 | 是 | 可配置 | 可配置 | 可配置 | 否 |
| 查看报告 | 是 | 是 | 是 | 是 | 是 |
| 管理成员 | 是 | 否 | 否 | 否 | 否 |

## 10. 旧系统功能处理

### 一期保留并重构

- 问卷、文件夹和问卷组
- 核心题型和逻辑
- 多语言
- 发布与回收限制
- JM 登录
- 答卷数据
- 基础统计
- 协作权限
- Webhook

### 二期实现

- 模板中心
- 主题中心
- 指定填写
- 公开查询
- 数据助手和提醒
- 高级分析

### 复用 JoyData，不在问卷内重建

- 用户、部门、岗位
- 游戏管理
- 通用消息中心
- 通用操作日志
- 流程审批

## 11. 成功指标

- 从创建到生成首个可用链接的中位时间小于 10 分钟。
- 80% 的常规问卷无需打开高级设置。
- 多语言问卷重复建表数量下降 60%。
- 国内/海外误发布为零。
- 答卷数据查询和导出时间下降 50%。
- 核心创建流程任务成功率达到 90% 以上。
